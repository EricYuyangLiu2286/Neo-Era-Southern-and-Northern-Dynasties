# 西秦「边疆诸部」：册封头人、驻军弹压、许以自治，两个地区各一组。六个按钮共用十二个月冷却。

nesnd_qe1_fr_afg_enfeoff_button = {
	name = nesnd_qe1_fr_afg_enfeoff_button
	desc = nesnd_qe1_fr_enfeoff_button_desc
	visible = { has_journal_entry = nesnd_qe1_frontier_journal nesnd_qe1_fr_afg_active = yes }
	possible = { nesnd_qe1_fr_no_cooldown = yes nesnd_qe1_fr_can_pay = yes }
	ai_chance = {
		value = 0
		if = { limit = { nesnd_qe1_fr_afg_value >= 60 gold_reserves >= nesnd_qe1_fr_enfeoff_cost_double } value = 20 }
	}
	effect = {
		custom_tooltip = nesnd_qe1_fr_enfeoff_tt
		show_as_tooltip = { add_treasury = { value = nesnd_qe1_fr_enfeoff_cost multiply = -1 } }
		hidden_effect = {
			if = {
				limit = { NOT = { has_variable = nesnd_qe1_fr_cd } }
				set_variable = { name = nesnd_qe1_fr_cd months = 12 }
				set_variable = { name = nesnd_qe1_fr_afg_enfeoffed months = 36 }
				add_treasury = { value = nesnd_qe1_fr_enfeoff_cost multiply = -1 }
				je:nesnd_qe1_frontier_journal ?= { add_progress = { name = nesnd_qe1_fr_afg_bar value = -15 } }
			}
		}
	}
}

# 许以自治：条到 50 以上才可用。AI 只在团结度低于 30 且身处战争时才用。
nesnd_qe1_fr_afg_autonomy_button = {
	name = nesnd_qe1_fr_afg_autonomy_button
	desc = nesnd_qe1_fr_autonomy_button_desc
	visible = { has_journal_entry = nesnd_qe1_frontier_journal nesnd_qe1_fr_afg_active = yes }
	possible = {
		nesnd_qe1_fr_no_cooldown = yes
		custom_tooltip = { text = nesnd_qe1_fr_autonomy_bar_tt nesnd_qe1_fr_afg_value >= 50 }
	}
	ai_chance = {
		value = 0
		if = { limit = { is_at_war = yes has_variable = nesnd_qe1_unity var:nesnd_qe1_unity < 30 nesnd_qe1_fr_afg_value >= 70 } value = 10 }
	}
	effect = {
		custom_tooltip = nesnd_qe1_fr_autonomy_tt
		hidden_effect = {
			if = {
				limit = { NOT = { has_variable = nesnd_qe1_fr_cd } nesnd_qe1_fr_afg_active = yes }
				set_variable = { name = nesnd_qe1_fr_cd months = 12 }
				nesnd_qe1_fr_autonomy_afg = yes
			}
		}
	}
}

# 波斯将军府「将军府的忠心」：两枚按钮是一组切换，选定的方略每月推动忠心（script_values 的 nesnd_per_stance_policy）。
# 默认接见边地使者、每月降低忠心。AI 不切换，所以 AI 的忠心按默认下降。
nesnd_per_stance_lean_qin_button = {
	name = nesnd_per_stance_lean_qin_button
	desc = nesnd_per_stance_lean_qin_button_desc
	visible = { has_journal_entry = nesnd_per_stance_journal NOT = { has_variable = nesnd_per_stance_loyal } }
	possible = { custom_tooltip = { text = nesnd_qe1_fr_cooldown_tt NOT = { has_variable = nesnd_per_stance_cd } } }
	ai_chance = { value = 0 }
	effect = {
		custom_tooltip = nesnd_per_stance_lean_qin_tt
		hidden_effect = {
			if = {
				limit = { NOT = { has_variable = nesnd_per_stance_cd } }
				set_variable = { name = nesnd_per_stance_cd months = 12 }
				set_variable = nesnd_per_stance_loyal
			}
		}
	}
}
nesnd_per_stance_lean_out_button = {

		custom_tooltip = nesnd_per_stance_lean_out_tt
