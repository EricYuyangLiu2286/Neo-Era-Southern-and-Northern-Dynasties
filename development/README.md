# 开发资料快照

本目录保存NESND项目技能、工程脚本、原计划与交接历史，以及本轮选取的验证摘要。它位于工作台源码仓库，部署MOD时不复制到游戏加载目录。

`nesnd-skill/`对应本机项目技能；`workbench/`对应本机nesnd-workbench子路径。原文与绝对路径保留，来源和SHA见snapshot-manifest.json。

这里没有复制本体基线、工坊素材、第三方工具二进制、原始大型存档或整组运行日志；原始证据仍由本机独立工作台保存。摘要中的文件SHA可用于核对。Python/Tiger/MCP及源码审查的通过不等于游戏验收。

当前用户允许玩家失国，玩家救援/日本旧终局备选均未选用。选定方向是实际事件顺序、目标可达性和运行验证。
