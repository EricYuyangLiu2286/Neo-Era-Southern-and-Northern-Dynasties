## 依赖图与最小实现

吴代明实际事件 → 旧`.21`变隐藏兼容dispatcher → 国别动态消息（观察或拒绝，原生局势繁荣不触发经济危机） → 可选外交JE → 选择仍存活的具体政府/反对领袖/国家利益伙伴 → 真实资格/财政/供给检查 → 发出7日请求与30日pending → 收件国重验并接受/拒绝 → 原生money_transfer或goods_transfer条约 → 原生维护/冻结/退出/违约 → 危机结束提示未撤回条约继续有效。

JE不增加战力、库存或全国生产率。HUS偏向实际反对领袖，FRA可保吴或扶反对派；QE1可联系SIH，SHA可联系共和HUS；BUR作为吴属国不能给反吴方送援，独立后再选择；MUG可联系FRA并在吴仍实际占迈索尔时提出区域主张（仅claim+外交代价，不夺地或发起战争）；英俄默认优先观察，仍有合法商业/财政参与空间。支持任一方都非必须；可中止，不凭稀缺判定失败。

援助候选量：每周500资金，或小武器10商品；仅一次接受，防重复堆叠。本国无违约/破产，固定净收入≥5000、现金储备≥26000才开放资金请求；该条件是承诺一年26000的保守预算选择，不是整个国家健康标准。小武器请求额外确认本国无当地短缺且当前价涨幅≤25%；原生出口cap、运输、双方市场权限仍由can_create_treaty完整检查。用户可通过正常条约UI谈不同数量。

约束期1年，不写成自动一年到期；约束期后仍持续，须原生撤回或重谈。提前撤回遵循原生on_break及infamy/关系后果。双方存续/战争/宗属改变在接受前复核，接受后交原生条约维护和冻结；不以结束JE偷偷删除已有条约。危机结束通知明确这一点。
