# 未使用本地化参考库

这里保存已退役事件的原始本地化，供 desc、story、information（说明类文本，亦称 Infomation）写作参考。归档目录不属于游戏运行时 localization/；需要采用文字时，先核对当前人物、地域、年代与效果，再在当前本地化文件维护实际使用的键。

按日期批次查 manifest.json，再按事件ID或关键词检索文本。每个批次记录原键、语言、来源文件及SHA、关联事件、作者类别和是否仍在游戏中共享。

- author：作者原作中已有的键；以保存的当前文本为准，并可用 original-20261030 核对早期版本。
- ai：后来新增的MOD文字，可以参考素材，不能冒认为作者原稿。
- paradox：本机原版文字参考，原版文件只读；不把其中历史设定直接当作NESND事实。

只移动MOD里已经没有有效引用的专属键。其他事件共享的键继续留在MOD，并在清单注明；原版键只复制参考文本。每份归档保留原键、语言头和文本，不在归档中改写正文。

2026-11-07批次：参见 [逐键来源与去向](2026-11-07-event-retirement/manifest.json)。空壳事件没有任何可解析文本时也逐ID记录，避免把“没有文字”误报成“已归档”。

2026-11-10批次：参见 [逐键来源与去向](2026-11-10-crisis-cleanup/manifest.json)。nesnd_crisis.10、.11 两个孤立事件的全部文字，仍作隐藏转发入口的 .21 的旧文字，以及四个无引用修正的名称，均为 AI 来源。
