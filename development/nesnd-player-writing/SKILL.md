# NESND 玩家文字

一个 MOD 同时有两种写作：脚本让游戏运转，本地化讲出舞台上的故事。二者对应同一件事，但声音不同。本技能管后者，并管两者在界面上的分工。

## 1. 两种声音

- **故事的声音**：日志正文、事件正文、引文、选项、按钮说明、修正名。有立场、有人物、有反讽，可以长。讲世界里发生了什么、谁在争什么。
- **规则的声音**：进度条名称与读数、条件提示、效果提示、状态行。短、准、带颜色和数字，不加修辞。讲玩家现在能做什么、要达到什么、会得到什么。

同一个事实只在一处说。规则不写进正文；正文不重复条件和数值。

## 2. 每个字段怎么写

样本全部取自作者原作（Git tag `original-20261030`），更多见 [author-samples.md](references/author-samples.md)。

| 字段 | 作者的写法 | 例 |
|---|---|---|
| 日志 `_reason` | 带立场的历史叙述，常以一个尖锐的问题收尾 | “似乎只要向工业经济注入足够多的资源，就能让整个法国乃至欧洲自动变成他承诺的‘和平且伟大之地’。事实真能如此吗？” |
| 事件标题 `.t` | 2–6 字，点出对象或用一个成语 | “异梦同床”“查理十世之死”“大游行”“‘万民书’” |
| 事件正文 `.d` | 一到数段。有具体的行动者、地点和利害；可以带叙述者的视角和讽刺 | “地权革命是经济上的革新，同样也是一项冷酷的政治运动。它要将一整个旧社会窃夺数千年的利益，转移到诞生不过数十年的新贵手中。” |
| 引文 `.f` | 有出处的引语、诗、口号或街头传言；可以极短 | “小小拿破仑，治国靠佞臣。岛夷非正主，依旧让民权！” |
| 选项 | 一个人物开口说话的表态，常带讽刺；不预告效果 | “有人要被畏罪自杀了。”“胡言乱语，正不必忧心。”“他们骂小拿破仑跟我……有什么关系？” |
| 按钮 `_desc` | 一句带立场的口号或理由 | “面包和马戏永远不过时。”“正义的事业总不缺支持者。” |
| 进度条与提示 | 只写机制，数字上色 | “稳定度变化：#g +50#!”“共和呼声进度达到#g 20%#!进度” |
| 修正名 | 2–6 字的政治标签，可以俏皮 | “拿破仑繁荣”“黑衣君主”“君主主义下水道” |

## 3. 不要这样写

- **代理的平衡腔**：“然而，一纸买卖契约并不能使失去田地的人立即找到新的营生。”每段配一个“然而”、每项成功补一句代价，是助手的口吻，不是作者的口吻。作者写“地权革命……同样也是一项冷酷的政治运动”，判断直接给出。
- **开发者的话**：“子日志”“按原规则”“此项事务随‘地权革命’一同结束”“统计口径保持一致”。玩家只需要知道现在发生了什么、能做什么。
- **否定对举与总结句**：“X 不是 Y，而是 Z”“这并不意味着……”“在……之间找到平衡”“既是机遇也是挑战”。
- **错位的称谓**：非中国政权不用“朝廷、军府、礼法”；南北朝制度按 `nesnd-victoria3/references/north-south-institutions.md`。
- **没有出处的引文**：不捏造史料，不冒署作者已有人物的著作。新写的台词可以，但要符合说话人的身份。

## 4. 写作步骤

1. **找样本**：在 tag `original-20261030` 的 `localization/simp_chinese/replace/` 里找同一字段、相近题材的作者原文（`git show original-20261030:<路径>`）。当前文件已混有代理文字，不能当样本。
2. **先列事实**：谁、在哪里、为什么、做了什么、结果如何；再核对脚本里真实的条件和效果，文字不能多于或少于脚本。
3. **按字段分配**：故事进正文和选项，规则进提示和进度条。原生 trigger 能显示的条件不再用 `custom_tooltip` 复述。
4. **对读**：把候选和同字段的作者原文放在一起读一遍：声音像不像，有没有平衡腔和开发者的话，事实和脚本是否一致。不像就重写，不是换几个同义词。
5. **批量时**（超过约 10 条）：整组连读一次，看是否反复用同一个开头、反问或收尾。

寻找退役文本素材时，查 [unused_localisations](resources/unused_localisations/README.md)：其中内容可作为 desc、story、information（Infomation／说明类）文本写作参考。先看逐键来源，区分作者、AI和原版文字，再核对当前设定与脚本；归档本身不参与游戏加载。

作者的改稿优先于任何代理稿。作者改了中文时，英文按改后的意思重写，不逐字直译。

## 5. 英文

- 英文要独立读得通，语气对应中文：讽刺的选项在英文里也讽刺（作者原作：“Bread and circuses never go out of style.”“Someone is about to 'commit suicide' to escape punishment.”）。
- 专名用作者已定的英文；不保留中文，不逐逗号直译。
- 动态代码（`[SCOPE…]`、`[concept_…]`、`#v …#!`）、数字和颜色与中文版完全一致。

## 6. 文字也是代码

- `.yml` 用 UTF-8 BOM 和正确的语言头（`l_simp_chinese:` / `l_english:`）。
- 动态引用要有保证存在的对象；概念链接查 GAME `common/game_concepts/` 的定义名。
- 每种语言每个键只在一个文件里维护，不用 `z_` 覆盖层。
- 字段、作用域与界面位置见 `nesnd-victoria3/references/journal-text-contract.md`。
