# 流散登记与迁移的独立检查

范围仅为流散本身。diaspora-supplement.py 从主 MOD 读取 JE、.3 选地事件、两组触发器与效果、进度条，按实际语法树执行。没有调用整合脚本里的其他国家测试。模拟采用真实 scope 层级，国家事件 ROOT 切换成来源国，任何未实现的运算/作用域立即报错。引擎原语（完整州判断、国家内文化集合的枚举、人口实际移动）按测试场景提供。docs/triggers.log:10066 定义 is_split_state；docs/effects.log:3864 明确 every_scope_culture 的 country 输入及 culture 输出；docs/effects.log:391 说明按文化的 country add_radicals.value 是每一 Pop 中向激进转化的比例，并非所有原住民汇总再反复处罚。

检查覆盖从有分割州和完整州的同一接收国择地、期间变成分割/换属/Pop合并、无人口或非美洲地点、旧事件错误 root、自我接收与跨来源接收、所有候选暂在交战以及恢复和平。无完整目的地时两个来源国仅对各自现存的原住民文化各执行一次 0.2，加总者不会随该文化的多个 Pop 行重复。已履行自己配额但仍标为原始来源的国家按现行设计仍是参与来源。普通国家和非原住民文化豁免。已结案的回调不能二次发放，成功结局只在真实余额清零后生效。最后一批3人与真实迁移0人另行验证。

主 MOD 最终 22 项断言均通过。分别植入错误选分割州、忽略战争、处罚局外人、翻倍处罚、虚记移动、删除来源国的和平路线筛选、保留失效旧来源这 7 项故障，7/7 均被断言捕获。原始快照在 diaspora-audit-preimage；其 JSON 及现行实装散列和结果分别见 diaspora-supplement-old.json、diaspora-supplement.json。此为离线 AST 测试，未运行引擎、使用 Git 或测试其他国家内容。

跨来源反例：A 已保存出发人群，A 与唯一合法接收国交战；B 同样有待迁人口但与该国和平。.3 对 A 选择失败之后，若保持该出发对象且不按可行配对重选，后续每周都对 A 重试，B 无法迁移。旧快照连续七周如实复现。实装的 .3 事件已在选不出目的地时释放旧来源，出发选择器也已筛出至少有一条和平完整路线的来源。采用固定选择首个合格国家的随机替身，旧快照七周后仍困在 A；同一场景在主 MOD 中 B 成功接手，七周内被配对或已迁出实际人口。单独撤去上述任一修复都会使回归失败。若所有接收地只是暂在交战，保留总配额，继续等待。

另一边界：若所有来源的合格原住民都已经因其他原因消失，但境外仍有完整接收州，未发生迁移的余款继续等待。按本轮“只有无目的地才失败、零真实迁移不能虚记”的范围，没有把它当作无目的地，也未建议给此情况强行发20%惩罚。
