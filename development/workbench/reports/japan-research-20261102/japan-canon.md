# 日本原设定核验（2026-11-02，只读研究）

本报告核对 PPT、人物文档、作者旧地图、两份日本专用计划文件和废弃 HOI4 工程。未改主 MOD、原稿、旧项目或技能，未启动游戏。`catalog.py status` 返回 Victoria 3 **1.13.11 / build 24799966 / CURRENT / changed_count 0**；这只是本机来源指纹检查，不是游戏验收。本研究没有实施脚本，故没有把旧 HOI4 语法作为 V3 接口证据。

**已确认的当前授权：** 作者明确要求“统一并有九州／统一但无九州／三国分裂”三个玩法分支，均按 `author_explicit` 处理；这不把任一分支升格为唯一历史正史。人物发生原稿冲突时以当前游戏为准，故沿用当前林汉涵等实际命名。下文的李／林及毛利／天皇对照只是来源记录，不重开已定命名或第三政权选择。

## 可直接用于后续设计的结论

1. **日本不是现实德川幕府开局的简单换名。** 作者文档明确有“大阪丰臣幕府”、吴国东洋领事府、在明吴军政体系任职的郑姓德川氏、长期吴日商业与海军合作。1835 地图把大阪幕府画作覆盖九州、四国和本州大部的橙色范围，德川家藩另涂色。[S1 第9页第4段、第27页第15–17段；S2 段455、576；M1 日本区域]
2. **PPT 的确定战后叙述是 1847—1852 年，且标题为“伟大和平——官方结局”。** 李汉涵出征、丰臣氏被认为忠明不忠吴、战后“四分”属于该未来线；不能据此宣称 1836 日本已分裂。四分实际为“吴直辖的九州与四国 + 丰臣残余 + 郑姓德川 + 天皇”。其中只有三个日本本土政权；原文的第三个不是毛利。[S1 第27页第1、16–17段]
3. **“统一并有九州／统一但无九州／三国分裂”是作者明确要求的三个玩法结果，原稿没有现成的三选一树。** 前两种可保持或改变既有统一结构；第三种有战后分治的明确原型。九州单独割让、保留四国、毛利替代天皇、统一路线的具体发动者，应分别记录当前设定依据或玩法实现方案。[本轮作者授权；S1 第27页第17段；M1]
4. **原稿异文已经记录，人物执行以当前游戏为准。** 核验原稿写“李汉涵”，不是“林汉涵”；当前游戏沿用林汉涵。PPT 写“郑（德川）家齐”“郑家庆”和“吴（井伊氏）直弼”。毛利家在已核原稿中直接见于十六世纪诸大名兴起；不据此退回当前人物或第三政权方案，也不假称旧稿已经写过完全相同的结局。[作者既有授权；S1 第15页第14段、第27页第15–19段；S2 段410；S3 段22、34、40、55]
5. **旧 HOI4 的民主、军部、天皇路线可以提供主题素材，不能当成统一正史。** `DMF` 的 tag 注释仍称 Great Yamato，大量国策仍写大和和天皇，但国家本地化、1936 剧本介绍已经写大吴郑氏。1936、1950 地图仍有大和体系。它们至少保存了互不完全相容的稿层。[H1:4；H2:139–156；H3:10；H4:85、93、117、141、265、291；M2–M4]

## 证据分级与使用约束

| 类型 | 本报告用法 |
| --- | --- |
| `author_explicit` | 作者明确要求三个玩法分支；此前已授权人物冲突以当前游戏为准。它们是当前执行依据，原稿异文不构成再次询问条件。 |
| `text_attested` | 已回读原始 OOXML 段落、原始图片或旧项目实际文件；只在该稿、该年代成立。 |
| `inference` | 由多条原文推得的政治利益、可利用关系，明确写“推断”。 |

## 幕府、军国与民主路线的可用材料

**幕府路线：** 资料最扎实的是丰臣的大阪幕府与德川家藩/大陆任官关系，适合从统治名分、诸藩服从、海贸与对吴依赖讨论改革；没有原文规定“武士地主→倒幕→明治维新”的现实模板必须发生。[S1 第27页第16–17段；S2 段455、576；M1]

**军国路线：** 旧 HOI4 国策直接写北一辉学习北明、西秦、东燕制度及陈东阳、列宁、孙文，提出“万族社会主义”；宫变路线清除民主派/内阁残党以巩固天皇权威；“新儒四派”在天皇授权下传播忠君和军国思想。[H4:117、141、291] 这些是旧工程的二十世纪政治分支，不能提前生成北一辉等人。若用于 V3，能借鉴的是“军队、君权、万族主义之间的政治组合”这一主题，具体十九世纪承载者和路径仍为 `gameplay_proposal`。

**民主路线：** 旧国策含“建立民主派议会”“民主灯塔”“现代六部制”“自由人的邦联”“恢复合邦省”，并明确把陈东阳、吉田松阴与“诸明治民主元老”列作新世界秩序思想来源；“民主灯塔”叙述声称 1918 军部窃国。[H4:82–97、309、313] 国策不是只有本地化：`Dawu.txt` 中“建立民主派议会”前置为 `DMF_weidituiwei`，下接“民主灯塔”，后者降低 fascism/提高 democratic 支持；“恢复合邦省”下接“自由人的邦联”。[H5:1028–1074、3826–3865] 这只证明旧 HOI4 的作者分支存在，没有核验其旧引擎是否可达；更不能用那些 effects 实现 V3。

**推断与提案边界：** 日本民主化可从本地幕府/商业与新儒传统、陈东阳思想传播发展，不必照搬现实西方开港叙事。民主体制、军事集权和名义君主可以分别组合；“民主必然亲东洲、军国必然反吴、统一必然吞朝鲜”都没有原文证明。任何这样的绑定必须是本轮有意设计。
