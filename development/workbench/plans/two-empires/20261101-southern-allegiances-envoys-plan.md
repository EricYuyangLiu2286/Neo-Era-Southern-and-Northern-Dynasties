## 2. 当前遣使实际流程

调用链：`common/scripted_buttons/nesnd_south_accords.txt` → effects同名文件 `nesnd_south_offer_chosen_accord` → `events/nesnd_south_accords.txt` 的 `nesnd_south_accords.1`。

1. 发起者是USM，已选明/吴，未违约、未在战争中、6个月邀请冷却结束且有合格成员。
2. 发起方承担6个月政府工资+3%、权威−25；各接收国写入4个月pending窗口。
3. **3天后**接收国收到“诸府约章”事件，弹窗有效3个月。按路线和成员身份显示守土/并省/日本让地等条款。
4. 接受不只是加好感：改写本国立场、签36个月盟约，写入并省或日本让地承诺，6个月立场冷却，与USM关系+15；拒绝清pending而保留原立场。
5. 目前AI接受基础权重40，同阵营+40，自主−30，拥明的海外成员+15，拥吴的大陆成员−20，吴方陆军超过接收国三倍时+25；拒绝35。权重须在有效选项间归一，不等于显示百分比。
6. 原版“资助游说团”属于独立外交行动，使用影响力、转移收入及游说团；当前代码没有把它接入自定义南朝立场。

因此截图中的四川变拥吴有代码来源：接受吴方约章会覆盖其立场。当前普通按钮又可在冷却后反复选边；本计划同时收紧全部写入入口，不能只藏按钮。

## 4. 一次选边、遣使重议、倾向显示

状态区分为：尚未表态 → 已表态 → 约章待回复/北方密使待回复 → 已确认立场或庇护承诺 → 战争结算。签约与选边分别存储，不拿cooldown充当一次性标记。

- 玩家首次明确选边后写永久本轮 `choice_committed`，**所有普通选边按钮同时消失**。AI初次选边也走相同落点。
- 普通季度AIreview不能偷偷改已确认立场；战前答复也不能再抽一次覆盖已选结果。
- 遣使是明确的重议事件。可变势力每次有效使团重新结算一次；固定100%M或100%W势力不重抽。玩家接收方亲自选择，概率只控制AI，不随机覆盖玩家刚作出的选择。
- 接受改变阵营时撤销旧承诺，再签新承诺；同阵营可续约。任何一次使团只能有一个有效回复，旧弹窗不得消费下一批pending。
- 普通选边锁与北方求援按钮共享：5%特殊分支不是可无限点击的额外抽奖。正在等待北方答复或已获庇护时排除南朝重复邀约，直到明确取消/过期/进入战争。
- 倾向展示由同一profile导出，使用六种带颜色的文字：**拥明、向明、中立、向吴、拥吴、自守**，不显示百分比。当前表态和潜在倾向分栏，以免“已拥吴但仍向明”被误认为显示BUG。
- 展示建议：固定或≥90%单边为“拥明/拥吴”；较强单边为“向明/向吴”；中立与独立合计占优且独立≥20%为“自守”；中立占优但不追求脱离为“中立”。阈值是UI提案，最终与profile一致集中维护。
- 移民、文化变动或旧档升级不应重新抽已承诺的立场。迁移只补缺失锁与profile版本；用户要重置开局基准通过新局完成。

外部验收：穷举允许写立场的调用者；普通按钮在点击后visible=false；旧事件/AI季度review不能绕锁；M/W固定势力不抽；同使团回复/延迟重复只执行一次；发起者消亡、换tag、交战、改宗主时安全取消。

## 5. 西秦与帝国密使

四川支线：SIH选择西秦 → QE1接收“川使请援” → AI接受30/拒绝70的基础权重 → 接受只记录保护承诺 → **内战日志结算爆发时**SIH解除对USM关系，成为QE1附属，进入QE1+SIH对USM的战争。拒绝转I，独立的实际外交与战争在同一爆发阶段处理。

襄樊支线：HNA选择帝国 → CNE接收 **“襄阳密使”** → AI接受20/拒绝80 → 接受在爆发阶段成为CNE附属并共同对USM作战；拒绝回M。写作素材按用户指定：朱斑博与牧仲棠会猎洞庭旧事、南朝现状、对帝国土地改革运动的期待。正式事件正文须回读作者人物原文，不能把此大纲当成已写成的文案。

原版语法已证：

- GAME `events/iberia_events/cuba_eventos.txt:250`：事件选项 `ai_chance={base=1 modifier={trigger={...} factor=2}}`，同文件另有factor0.5、0，证明乘法修饰可用。
- GAME `events/india_events/mughal_events.txt:85`：`ai_chance.modifier.trigger`内的 `has_attitude={who=... attitude=...}`。
- 本机 `triggers.log:10109`：has_attitude为**当前country看待who**的方向性判断；不能倒置。
- 截图证明的是USM对QE1“和善/+150”，不能由此断言QE1对USM同样友善。relations是双边好感，AI attitude是另一变量；两者分开。

建议乘数（待调参）：主要看接收者QE1/CNE→USM，友善×0.25，敌对×2，其余×1；USM→接收者友善再×0.75，敌对×1.25，其余×1。只乘接受权重，拒绝保持70或80。**不能把“30%×乘数”直接当最终概率**：

`P接受 = 接受基础权重×乘数 / (接受基础权重×乘数+拒绝基础权重)`。

无修饰为30%/20%；若双方均友善，总因子0.1875，西秦接受约7.44%，帝国约4.48%。计入本国5%求援后，分别约0.372%与0.224%成为北方保护分支。这只是建议参数；不改变用户给定的基准70%/80%拒绝。

时序必须先结算独立/北方保护阵营，再选南朝反吴盟主、创建战争、加入后援；否则新宗主附属会被旧`is_subject=no`筛掉。禁止把“加入目标后援”视为已经开战。已有同一战争则加入，不重复开第二场；不存在/已停战的play不引用。北方拒绝、接收国被吞并、承诺过期、USM不再是吴朝分别写独立收尾。

## 7. 权重重算：以大陆文化核心为主，避免小殖民地堆票

开局清点：33个USM直接附属；另有SHS→BUR、MGD/SUL→PHI三个间接成员，避免重复计算。完整人口、主流文化、首都清单在 `WORK/reports/south-allegiance-plan-20261101/membership-inventory.json`。

核心谓词必须同时满足：任一**主流文化**具有 `tradition_sinosphere`，且首都在明确的中国大陆state_region集合中。不是人口多数文化，不按Tag名字推测。DAI的vietnamese确有中华文化圈传统，但首都不在中国大陆，故不进大陆核心。台湾、海南是否算“大陆”应显式排除；现有宽泛China列表不能直接冒充大陆集合。

原版依据：GAME `common/scripted_triggers/00_coa_triggers.txt:496` 的any_primary_culture迭代，`common/scripted_triggers/00_clothes_triggers.txt:1237` 的has_discrimination_trait；按culture scope拼接。国家首都→state_region依实际history与country_definition核。

建议四组政治份额：大陆核心60、日本15、区域藩王15、其余海外10（各组不存在时再归一，不删失国成员来无限刷分）。核心初始HNA22.5、SIH22.5、GNG15；BUR约4.78、SIA4.96、DAI5.26；日本三政权出现后共享日本组，不凭新tag增票。

## 8. 精确枚举与和平难度

吴方和平更难：SIH/HNA/GNG各只有5%W，三家都W仅0.0125%；再要求日本同意让地，初始JAP缺口若放W后还需乘10%。B的最优分数环境下，全部必要条件的枚举上界约0.0003%。日本拒绝九州后W=0，若仍坚持日本让地为完整吴方和平条件，则该阶段严格和平统一不可达。这是明确的分支结果；不能偷偷调AI概率来假称双方同难。可以另设未统一的和局，但必须与“完成全体和平并省”区别。

压力时序：当前每月通常+3，约20个月就会碰到和平要求pressure<60；还需连续12个月。不能再随意把观察期拉长到18个月。1837下半年陈案、1838初保底、1839初战争期限继续保留。和解的−3与基准+3通常抵消，不得称作必然降压。达成合格盟约后AI应停止破坏性重邀，给持续履约留下窗口。
