# 国家界面皮肤贴图

每件以本体 `gfx/interface` 同路径 DDS 为尺寸原件。出图前读取其宽、高、透明轮廓，查 GUI 的分帧、九宫格边距、平铺和镜像用法。把原始画布比例和每帧像素尺寸写入出图提示。

生成后实测画布和有效图案。以整数交叉相乘核对宽高比。只允许等比缩放以及撤去出图工具额外添加的画布留白。保持原件的画布尺寸、控件所需的透明区、角饰锚点和分帧边界。花纹金属、木雕和镂空边框可随图案变宽变窄，最宽处可厚于原件。保留镂空负形和控件净空。装饰限于 GUI 固定边距，需铺排的区域能连续衔接。画错比例、轮廓或帧位就重出，禁止用非等比拉伸补救。

按原始像素和 GUI 的实际显示尺寸各看一次。证券雕版用有粗细层次的刻线、交织扭索和疏密留白表现；缩到界面尺寸仍应读得出主纹，原寸可见细部刀线。

速度表的黑色轴座直接以本体同路径 DDS 为模板。将孔口、抗锯齿边缘和下沿阴影在原坐标逐像素比对 RGBA，同时逐行核对内圈左右边界。宽饰带向孔外扩展；保留游戏叠加件的净空。

封装后重新读取 DDS 头和首层图像，核对原路径、宽高、原件像素格式、mipmap 层级和各帧几何。某件重出后仍不合格，留给本体回退。

中华帝国的大块章面用整只金麒麟，小件抬头和转角用正面的金虎浅浮雕，配不透明绛红珐琅座。顶栏简式端饰的虎扣在 416 × 160 原件上实测 31 × 32 像素。其他扣位按固定边距和实际显示尺寸分别配准。对应状态帧保持同一扣位。大明联邦的朱砂扣及同形灰阶扣使用同一枚小篆“夏”字，逐帧从 DDS 读回核对。
