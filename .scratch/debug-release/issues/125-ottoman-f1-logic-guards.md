# 125 奥斯曼：已合并日志的入口、判序与守卫（F1）

## 1. 现象与期望

全局盘点查出已合并的奥斯曼日志（B2–B6）有三类硬伤：入口读「正在进行」而原版事件可能早已结束，整条线开不出来；好坏结局同月成立时先判好的；奥斯曼成了附属、失去首都或改了标签后，日志照跑或被补加重开。本批只修这些，不加新日志，不调数值。

## 2. 改了什么

- **共用文件**（新建 `common/scripted_triggers/nesnd_ottoman_common.txt`、`common/scripted_effects/nesnd_ottoman_common.txt`）：`nesnd_ottoman_can_act_abroad`（不是附属且持有东色雷斯全境）、`nesnd_ottoman_state_outside_ottoman_hands`（州的持有者不是奥斯曼，最上层宗主也不是奥斯曼）、大东方危机记录与结果触发器、对持有者的最上层宗主设征服目标的效果。
- **入口读「发生过」**：
  - 月度记录 `nesnd_ottoman_gec_monthly`：原版大东方危机开启的那个月记下奥斯曼在巴尔干持有的州地区；危机结束后记下「遏制」或「失控」（原版两个结果修正是限时的）。
  - 鲁米利亚入口由「危机正在进行」改为读原版全局变量 `eastern_crisis_happened`；快照优先用危机开启时的记录；结局读修正或记录。
  - 学院入口不再要求原版教育子目标；做过的，第一环多一条可见的完成条件，直接完成。
  - 事件「宪政的帝国」直接加学院第一环；事件「苏丹的帝国」满足条件时直接加鲁米利亚、东方诸省。月度补加保留。
- **奥斯曼自身状态**：
  - 「伊斯兰领袖」新增结局「失去自主」：连续 12 个月无法自主对外即结束，给永久修正 `nesnd_ottoman_lost_autonomy`（威望 −10、合法性 −10），宣称保留。
  - 72 个宣称按钮的 `possible` 改调 `nesnd_ottoman_claim_possible`，多一条「能自主对外」。
  - 各日志的隐藏失效结局都写本日志的关闭变量；「重整东方秩序」「帝国诸民」的 `possible` 加读关闭变量。「帝国诸民」只在不再是奥斯曼时写（州数不足仍可重开）。
- **判序**：「重整东方秩序」先判「旧秩序的终结」；「伊斯兰领袖」顺序为失去自主、失败、领袖、超时；「宪章与军营」两边同月达成时总分高者胜，平分按事件 .5 的倾向。
- **去写死国名**：事件 .3「继续东进」的五州改为「不在奥斯曼及其附属手里」，征服目标设给各持有者的最上层宗主；宣称按钮对埃及改为「埃及不是奥斯曼的附属」；`nesnd_qinist_origin_country` 的裸 `c:PER`、`c:QE1` 改 `?=`。
