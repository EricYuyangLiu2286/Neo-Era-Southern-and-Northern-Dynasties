## 起因与开局

## 请求与回报

- 王公、印度帝国和合格的南洋小邦共用「出使求援」。外交议程的出资与索援仍由 external 系统处理。原共同防御、自治、独立和统一继续走原有按钮与答复。
- 点击国名打开 `nesnd_india_diplomacy.4`，选人后才生成报价、登记六个月冷却，并于次日向该国发送 `.1`。援助国作答时复核对方身份、宗主、人员类别、战争、待办序号、资金与对应回报条件。受援国保留拨款、四年修正和四年获批锁。关系仍增加 25。
- 每个 AI 请求国独立按月尝试。采用 14.26% 作为三个原 5% 机会的合并近似值；候选国数量不会放大尝试次数。一次加权抽选在所有可联系国家之间分配。USM 直属邦向远南、日本、USM 的权重分别为 6、3、1，自治领身份和和平条件会剔除不合格目标。其他属邦联系直属宗主，独立国对所有可选国等权。AI 接受权重对三类援助增加一项，当请求国有州位于援助国有利益标记的战略区时加 20，仅加一次。
- 每次接受在请求国执行 `set_owes_obligation_to`，债权人为实际援助国。这个原生效果设定双边义务状态，已有同向义务时不会生成多张可分别兑现的欠条。教师使团令援助国影响力 +25，期限 48 个月，再次派出会刷新同名修正。军官使团建立从请求国授予援助国的军事通行条款，五年为约束期，届满可退出。重复条款等无法签约的情形由原生 `can_create_treaty` 在接受前检查。
- 接受悬停将义务、特定回报、关系各写一行，拨款另用原生国库预览。三行均用 `custom_tooltip_no_bullet`，取消原先可能因长句换行而独占一行的项目符号。视觉结果留待游戏内确认。中英文按钮、选人事件、援助修正和所有依赖该顾问团的提示已对齐。

## 工程师的等级与产权

工程师拨款按每 £25,000 折算一级工具作坊产权，向下取整，最低一级，最高五级。出使时保存的实际报价决定这份协议的级数。£50,000、£75,000、£100,000、£125,000 分别约定二至五级。此前使用的 600 是原版工具作坊每级需要的建造力。此次调整只用于使团投资。

约定指援助国政府在这座作坊至少应持有多少级。已经达标就保留原数。需要补足时，给该国政府写入约定数，保留其他持有人的产权。优先选首都州。若首都不合适，则在其余可兑现协议的州中选人口最多的。导出的 `docs/effects.log` 记载了 `create_building` 的 `level` 与 `add_ownership` 两种互斥写法。这里使用后者。已有工场时，两笔投资是否指向同一持有人会影响结果。

| 同一工场的先后写入 | 1836-02-21 观察者存档结果 |
|---|---|
| 昆士兰棉花种植园，先写自持 5、福建金融区 5，再写自持 2、广东金融区 7 | 工场 4231 总计 14。自持变为 2，福建原有的 5 保留，广东新增 7 |
| 日本东北铁矿，两次分别写浙江铁矿 5，再写当地铁矿 4 | 工场 3746 总计 9。浙江仍持有 5，当地持有 4 |
| 西孟加拉丝绸种植园，先写西孟加拉庄园 2、南京庄园 3，再写东孟加拉庄园 3 | 工场 2980 总计 8，南京原持股完整保留 |

写入出处为源目录 `common/history/buildings/13_australasia.txt` 第 385、424 行，`11_east_asia.txt` 第 6401、6469、6482 行以及 `10_india.txt` 第 215、295 行。旧存档佐证历史初始化中不同持有人并存，同一持有人再次写入可重设其级数。运行中给外国政府写入产权仍需下列复测。国家查询把该国政府和私人投资者的持股相加。脚本同时读取整座工场由各国政府持有的总级数，以此估算援助国政府持股的上下限。下限已达约定数时不再写入。如果上限未超过约定数，可安全补足。上下限分跨约定数时，无法查清该国政府准确的持股，改找合适的州。全国都无法兑现时，工程师请求不能获准。

本轮逐条复读两种语言的使团正文、选项和悬停。工程师回报直接写明哪些产权归援助国政府，选人事件改用向对方提出的聘请条件。

## 游戏内复测（1.15.1）

以下为供作者执行的独立测试，建议在暂停的临时新局分支中进行。每次从同一未发出请求的基线读入，可避免六个月冷却和四年获批锁影响下一例。控制台使用本机已有记录的 `tag`、`effect` 和 `add_journal_entry`；后者仅在日志尚未挂载时使用。选择事件需要请求上下文，从日志按钮进入。

1. 新局暂停，`tag AWA`。阿瓦德的宗主应为 FRA。打开「出使求援」，应只有一个具法兰西国名的按钮。点后在阿瓦德选择三类顾问之一，次日回应方应为 FRA。
2. `tag COC`，科钦应为 USM 傀儡。远南为自治领、日本为朝贡国时，应有 USM、YN1 两个按钮。在临时分支 `tag YN1` 后执行 `effect = { make_independent = yes }`，再 `tag COC`，应仅余 USM。在另一分支让日本独立，再以 USM 执行 `effect = { create_diplomatic_pact = { country = c:JAP type = dominion } }`，核对远南仍是自治领时三钮并列。州名迈索尔是 USM 直辖地，新局 MYS 无领土，不能作为切国样例。
3. `tag GAR`。加瓦尔独立，候选 12 国均存续且和平时应有 12 钮。以其他国家在临时分支吞并 PRU（如 `tag FRA` 后执行 `effect = { annex = c:PRU }`），再 `tag GAR` 查普鲁士按钮消失。另可在某援助国参加第三方战争期间查该钮消失，和平后查其恢复。
4. 自同一未派使的存档分别测试三类援助。请求发出后立即暂停并 `tag FRA` 或切至所选援助国，前进一天。必要时以援助国执行 `effect = { add_treasury = 125000 }` 保证可支付。悬停「接受」，检查独立的义务、分类回报、关系与扣款，再接受。双方外交页应显示请求国欠援助国义务，关系 +25；请求国应收到报价全额、顾问修正与对应四年修正。
5. 教师测试用两个不同请求国先后联系同一援助国，查后一次的到期日顺延、影响力仍只加 25。工程师测试前后记下首都州工具作坊的等级和产权明细，分别检查空州、已有其他股东、援助国政府已持有产权三种情况。遇到首都不合格的多州请求国时，核对次选州确为合格州中人口最多者。另用已有四级的工场测试一级约定，接受后仍应有四级。再以已有一级的工场测试三级约定，应补到三级。军官测试检查条约页的授予方、可通行方和五年约束期。
6. 让两个不同属国分别选择远南与 USM。若远南在请求送达后失去自治领身份，旧请求应失效。另读一个改动前的旧档，核对已有宗藩未重分配，并在日志月度刷新后检查按钮国名。
