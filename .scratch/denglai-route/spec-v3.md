## 0. 这一版改了什么

| 作者的意见（2026-11-10 第三轮） | 这一版的做法 |

## 3. 主线

### J0 雪国共和（根）

- **开局**：事件「雪中的抉择」，整军或通商，不可更改。
- **身份**：修正「唯一真正的共和国」。北朝变共和国或共和军立国时换成「共和不孤」。
- **政体锁**：占有山东之前，君主制、神权制等政体不能提案。被革命或外力改掉时给 10 年惩罚，日志链继续。
- **每年随机事件**（约 30%，6 个）：齐国旧族与复辟派；女真人的地位与贩奴的旧账；雅库特人要席位；审查报纸；北朝来使重提库页；新一批流亡者到岸（北朝镇压共和派之后）。
- **最后一段**（占有华北或华南的州之后显示）：把原版要求摆出来——泛民族主义、成为 CHI 候选、区域内 75% 的州。战争路线一个按钮「誓师」，和平路线一个按钮「颁布共和宪草」。东燕与同盟成员是天然支持者（同集团支持分 +25，`GAME/common/defines/00_ai.txt:197`）。
- **完成**：登莱成为 CHI（共和、非共和两段文字）。**失败**：别国先建成。**超时**：不设。

### J1W 远北的阴谋（战争）

| 项 | 内容 |
|---|---|
| 目标 | 让俄属远北的辽东同乡自己闹起分离，再把分出来的国家并进来 |
| 第一段：煽动 | 按钮**接济远北同乡**：对俄国建立原版的“支持分离主义”关系（由脚本直接建立，不等民族主义科技），并定期让伊尔库茨克、上叶尼塞斯克的非俄族人口激进化（动荡越高，这些州越容易跟着分离）。之后运动的产生、壮大、被镇压全走原版 |
| 进度条 | 「远北人心」：每周读取原版的辽东人分离进度并显示，不另算一套 |
| 俄国怎么应对 | 原版手段都有效：镇压运动、提高接纳度、打赢分离战争。分离被平定时弹事件「退回雪线」，冷却后可再接济 |
| 第二段：发难 | 条件是**分离已经成功**：伊尔库茨克不再属于俄国，也不属于登莱。此时弹事件「远北起事」：登莱与俄国之间建立停战；按钮**归并远北**解锁，对新生国家发起专用博弈，要求它并入。这个博弈类型不允许俄国卷入 |
| 其他按钮 | **整编义勇**：分离进度过半后可用一次，在雅库茨克编成若干营。**向东洲订购军械**：付钱换 24 个月军队修正 |
| 事件（5） | 远北起事；成功「湖东」；退回雪线；随机 2 个 |
| 完成 | 登莱占有伊尔库茨克的土地 |
| 失败 | 归并博弈打输：军队集团不满 |
| 超时 | 12 年，照样推进 |

配套的数据小改已做（见第 6 节第 1 条）：伊尔库茨克、上叶尼塞斯克加了辽东人的祖地；伊尔库茨克的辽东人调到 8 万（占 22%，够得上原版产生运动的门槛）。

### J1P 黄金与同盟（和平）

与第二版相同：三项原生条件（金矿、人口、与东洲同市场或有投资条约）；按钮「勘金」「招徕流民」；外交行动「请东洲商社入股」「居间调停」「共倡同盟」。超时 12 年。北海公司在这里成立最顺（见第 5 节）。

### J2 复燕（共用）

与第二版相同，三处调整：
- 分地后，拥有海参崴所在州即可用决议**「定都海参崴」**：弹事件二选一，留在原都或迁都，选过就消失。迁都时行政迁出勘察加，勘察加、鄂霍次克降为未整编，留作镇守，华北人南迁。
- 和平路线：登莱不参战，东燕立住之后按约割让。
- 起事失败或 12 年未起事：不再强制“以库页为都”，首都不动，主线照样推进；东北的辽东人、女真人进入垦殖和招徕流民的人选。

东燕：TAG `YAN`，主流文化辽东、女真，君主制。君主由代理拟一个徐氏远支。起事范围：外东北、黑龙江北、松江、黑龙江四州。（2026-11-11 作者更正：起事范围是东北六州，辽东、吉林在北朝手中时一并划给东燕；上面四州是起事的必要条件。）（2026-11-11 再更正：外东北已分为海参崴（原键）与勃利两州；起事前提为松江、黑龙江、黑龙江北、海参崴、勃利五州；乙约改为登莱取得黑龙江北与海参崴整州，大燕保留勃利。渡海结盟分支见 issues/14。）

起事的力量对比（作者 2026-11-10）：
- 东燕起事时有 50 个营（40 步兵、10 炮兵）。北朝开局不算征召兵约 120 个营。
- 北朝得到 6 个月的修正「东燕之乱」：陆军士气损失 +25%、防御 −10%。燕国旧部起事，受过旧燕恩惠的地主、军头士气低落。
- 北朝在这场战争里持有“吞并东燕”的战争目标（写法同镇压共和军，`common/war_goal_types/nesnd_cne_republic.txt:3`）。
- 北朝打赢后，起事前已整编的州（松江、黑龙江）收回时由 on_action 直接恢复整编，不让北朝因为这场叛乱白丢本土。

### J3W 渡海 / J3P 齐鲁之约

与第二版的 J4W、J4P 相同。完成时：
- 决议**「还都青岛」**出现：占有山东即可用，只有迁都一个结果，并使「定都海参崴」失效。
- 政体锁解除，J-M 开启。

## 4. 旁支与政体

### JC1 海外落脚点

| 项 | 内容 |
|---|---|
| 开启 | 登莱拥有外东北或黑龙江北（有了不冻港）；或 J2 已结束 |
| 目标 | 在非洲拥有一个州或一个通商口岸。有了它，登莱在该战略区的介入度保底 1500，才谈得上殖民和博弈 |
| 指引 | 日志列出候选地并说明各自怎么拿：**索马里兰的苏丹国**、**马达加斯加**（未承认国，可战可买）；**肯尼亚沿岸**（部落地，可直接殖民，但要先有介入度）；**向大明租借莫桑比克一带的口岸**（只能和平） |
| 战争手段 | 按钮**选定登陆地**：在候选里选一个州，登莱取得对它的宣称。宣称本身就给介入度，之后由玩家用原版征服博弈 |
| 和平手段 | 外交行动**租借口岸**（对该州的主人；同意则割让通商口岸，登莱付款）。也可以用原版条约买州 |
| 弱国原则 | AI 登莱只在对方没有强国保护、且自己不在别处打仗时才选战争手段 |
| 完成 | 在非洲有一个州或口岸 → 开启 JC2，并提示成立登莱远洋公司 |
| 超时 | 10 年。无惩罚，以后自己拿到非洲领土时 JC2 仍会开启 |

### JC2 垦殖

| 项 | 内容 |
|---|---|
| 开启 | 登莱在非洲有州 |
| 目标 | 建起足够大的殖民地网络：在非洲控制 7 个州（含附属国，与原版瓜分非洲相同） |
| 殖民本身 | 用原版：殖民法律、疟疾预防、介入度。日志期间殖民速度 +50%；按钮**倾力垦殖**：点一次持续 12 个月，殖民速度再 +50%，行政力 −20% |
| 迁徙进度条 | 「垦殖船期」0–100，每周推进。满 100 时在本轮选定的人群里随机抓一批迁到本轮目的地；前后各数一次，确实迁到了才算成功。抓不到人（没有符合条件的人口、来源国与登莱交战、目的地已不属于登莱）就提示“本轮迁徙失败”，归零。然后自动开下一轮；连续失败则停下，等玩家重选 |
| 每轮的选择 | 按钮**改选目的地**（在登莱的非洲各州间轮换）；按钮**改选人群**（在已放宽的档位里选） |
| 人群档位 | 第一档：北朝境内的华北文化知识分子与贫民。第二档：东北的辽东人、女真人（不论复燕成败）。第三档：朝鲜人（有密约或朝鲜已亡）；俄属远北的同乡 |
| 加码按钮（3） | **加开船期**（进度加快，付钱）；**扩大每批人数**（付钱，分三级）；**放宽人选**（解锁下一档，要求一定的识字率或港口等级） |
| 代码安全 | 目的地每次迁徙前重新确认属于登莱且有人口；人口对象失效就按失败处理；不向无主地迁徙 |
| 事件（4） | 第一船；垦殖民与当地人；迁徙失败；完成「远洋的共和国」 |
| 完成 | 州数达标 → 修正 |
| 失败 | 在非洲一州不剩 |
| 超时 | 30 年 |

### J-M 君主主义阴谋

| 项 | 内容 |
|---|---|
| 开启 | 政体锁解除（占有山东）。山东有 1200 万人，地主与农民一下子成了国内最大的势力 |
| 开启时 | 创建一个运动：默认**立宪君主派**（齐国旧族）；已研究法团主义时改为**法团派**。同时自发的**反动派**也算在内 |
| 进度条 | 「阴谋」0–100，每月变化，各项具名显示。**上升**：地主、乡村民众、军队中有势力强大或在政府里的；合法性低；激进派比例高；生活水平下降或破产。**下降**：这三个集团都不举足轻重且不在政府；教育、警察等机构达到等级；研究完指定的中后期社会科技 |
| 随进度变化的修正 | 一个按进度缩放的国家修正：提高上述运动在各州的吸引力。进度越高，运动越大 |
| 玩家的干预（2 个按钮） | **查办复辟党**：花权威，进度下降，激进派上升。**公布旧族账册**：付钱，一段时间内压低吸引力 |
| 完成 | 进度降到 0 并保持 12 个月，或三个集团都边缘化且机构、科技条件齐备 → 运动失去加成，事件「共和已稳」 |
