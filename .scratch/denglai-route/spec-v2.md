## 0. 这一版改了什么

| 作者的答复 | 这一版的做法 |
|---|---|
| 登莱很弱，不能鼓励 AI 自杀 | 每个要动武的环节都分两段：先煽动（进度条），看到对方真的乱了（原生状态）才解锁“发难”。全链共用这条规则 |
| 殖民非洲是主要手段，要先有东北出海口，人口不从国内来 | 新增共用日志「复燕」取得出海口，再接共用日志「出海」：迁都、殖民，垦殖民从东燕故地、朝鲜、北朝流亡者里招 |
| 煽动燕国复国主义，联络朝鲜，事后分地 | 「复燕」：辽东人、女真人起事，建立东燕（新 TAG）。登莱取一部分，其余归东燕；战争路线东燕是附属国，和平路线是盟友 |
| 请求可以失败，但不能卡死；可用自定义外交行动 | 向别国提的请求都做成自定义外交行动；每个日志有超时出口，超时也推进；门槛读真实领土 |
| 可以削弱北朝，但不碰它的日志变量 | 只对北朝的人口、利益集团、政治运动下手，经原生状态传导（北朝信心本来就读激进派比例） |
| 东洲市场两种情况 | 东洲还在共同市场时“居间调停”；东洲退出后“共倡同盟” |
| 完成特定条件前锁政体；真变了给限时惩罚 | 回到山东前不能提案改政体；被革命或外力改掉时给 10 年惩罚，日志链不中断 |
| 以海参崴为都最好；海路也可以 | 「复燕」成功即以海参崴为都；失败或超时以库页为都，照样往下走 |

规模：**8 个日志**（上限），每条路线走 6 个；进度条 3 条；按钮约 10 个；自定义外交行动 6 个；事件约 36 个；新 TAG 1 个（东燕）。比第一版大，原因是新增了「复燕」和「出海」。

## 2. 树

```
J0 雪国共和（根；开局事件一次选定路线）
│
├─【战争】J1W 远北旧土 ──┐
├─【和平】J1P 黄金与同盟 ─┤  积蓄国力（一）  1836–1848
│                         ▼
├─ J2 复燕（共用）            积蓄国力（二）：东北出海口，海参崴
│        │                    成功 → 以海参崴为都；失败/超时 → 以库页为都
│        ├──────────────┐
│        ▼              ▼
├─ J3 出海（共用）    【战争】J4W 渡海 /【和平】J4P 齐鲁之约
│   迁都、非洲殖民        回到山东（与 J3 同时进行）
│                         ▼
└─ J5 华夏（共用；接原版候选统一）
结局：登莱成为华夏（共和 / 非共和两种文字）；别国先建成华夏（失败）
```

### 全链共用的规则

1. **先煽动，后发难。** 进度条满只是“可以起事”；“发难”还要求对方处于原生的乱局（见各日志）。AI 登莱只在两者都满足时动手。
2. **请求用外交行动。** 购地、开埠、入股、密约、同盟都做成只有登莱能发起的自定义外交行动，对方按自己的处境决定。被拒只有冷却，不扣进度。
3. **不卡死。** 每个日志超时都推进到下一环，只是结果差一些；后面的门槛读真实领土和首都，不读“上一环是否成功”。
4. **新变量**：路线、走到第几步、行动锁（定时）、新都所在州，共四个。
5. 所有日志 `can_revolution_inherit = no`、`transferable = no`；登莱灭亡即失效。

## 3. 各日志

### J0 雪国共和（根）

| 项 | 内容 |
|---|---|
| 开启 | 开局即有；数日内弹事件「雪中的抉择」，二选一，不可更改。AI 偏和平 |
| 目标 | 回到山东，建立华夏；“唯一真正的共和国”的身份贯穿始终 |
| 状态量 | 无进度条。显示原生条件：政体、走到第几步、首都 |
| 政体锁 | 回到山东（占有山东的土地）以前，君主制、神权制等政体法律不能提案（`can_enact`，带说明）。被革命、政变或外力改掉时：事件「雪落无声」，10 年惩罚修正，日志链继续 |
| 身份修正 | 「唯一真正的共和国」，共和制存续期间保有。北朝变成共和国、或共和军立国时，事件「不再孤悬」，换成「共和不孤」 |
| 每年随机事件（约 30%，共 6 个） | ①齐国旧族与复辟派（建国时被击败的贵族残党，君主制的支持者仍在）；②女真人的地位（如今占两成多；共和国靠贩奴起家的旧账）；③雅库特人要席位，而法律是文化排斥；④共和国仍在审查报纸；⑤北朝来使，重提对库页的宣称；⑥新一批流亡者到岸（北朝镇压共和派之后才会出现，带来华北人、西北人） |
| 完成 | 登莱成为 CHI。共和制仍在：结局「华夏中洲共和国」；已不是共和制：另一段文字，不给共和奖励 |
| 失败 | CHI 已由别国建立 → 事件「华夏有主」 |
| 超时 | 不设 |

### J2 复燕（共用·积蓄国力二）

| 项 | 内容 |
|---|---|
| 开启 | J1 结束（完成或超时） |
| 背景 | 东燕 1819 年退到辽东，1824 年被牧仲棠灭于黑龙江源。辽东人、女真人是它的遗民和旧都司；外东北 107 万人，辽东人 50 万、女真 21 万 |
| 目标 | 借燕国复国主义取得东北出海口 |
| 进度条 | 「燕旗」0–100。月度项：北朝在打仗；北朝地方失序 ≥30；外东北、松江等地动荡；与朝鲜有密约；「资助会党」生效中 |
| 按钮（1） | **资助复燕会党**：付钱，12 个月内每月加进度，并让东北各州的辽东人、女真人激进化 |
| 外交行动（1） | **朝鲜密约**（对朝鲜；朝鲜存活时可用）：同意则进度加快，起事后朝鲜对东燕、登莱关系上升，并成为垦殖民来源。朝鲜已亡时改为事件「朝鲜流亡者」，给一次性进度 |
| 发难的条件 | 进度满，**且**北朝处于战争、革命、与共和军交战，或地权革命已失败 |
| 起事 | 事件「燕旗再举」：以北朝的外东北、黑龙江北、松江、黑龙江四州建立东燕，北朝与东燕开战（写法照现有的北朝共和军：先易帜，后打仗）。同一事件里分地：**甲** 登莱取外东北与黑龙江北（海参崴归登莱）；**乙** 登莱只取黑龙江北，另在海参崴得通商口岸，东燕更强。战争路线：登莱参战，立即得地，东燕是登莱的保护国。和平路线：登莱不参战，出钱出械，东燕立住之后按约割让，两国结盟 |
| 事件（6） | 燕旗再举；分地；成功「海参崴」；失败「燕旗落」；随机 2 个（旧都司的名册、北朝清丈队驱赶女真人） |
| 完成 | 战事结束时东燕存活，登莱占有约定的土地 → 新都定为海参崴所在州 |
| 失败 | 东燕被北朝吞并 → 事件「燕旗落」，新都定为库页 |
| 超时 | 12 年未起事 → 新都定为库页 |

辽东（盛京）、吉林不在起事范围内：那是北朝共和军东北起事的地方（`common/scripted_triggers/nesnd_cne_republic.txt:2`），两者不重叠。

## 4. 北朝内战两种情况

**爆发**（共和军起事）：
- 起于山西：帝国西顾。J2、J4 的发难条件都满足。
- 起于辽东、吉林：与东燕同在东北。若东燕已立，两者是邻居，事件里让玩家选择与共和军的关系；若未立，J2 进度加快。
- 起于山东、直隶、北京：山东在共和军手里。战争路线遇到「两个共和国」；和平路线可按“会盟”完成。
- 共和军胜、北朝改共和：J0「不再孤悬」。和平路线多一个盟友；战争路线再打就是共和国打共和国。
- 帝国平定共和军：窗口关闭；流亡者到登莱（J0 事件⑥）。

**不爆发**：
- 地权革命成功：最难。只能等北朝对外战争，或靠「接济北朝共和党人」「结交北朝地主」慢慢把激进派推过 15%，让北朝自己的信心下降。
- 地权革命失败：发难条件直接满足。
- 一直在改革中：读失序条。
