# NESND 部署白名单（deploy.ps1 逐行读取）
#
# 唯一标准：游戏或启动器在运行、加载本 MOD 时会不会读取这个文件。会读取的部署，其余一律不部署。
# 判断不了的写成 doubt：不部署，预览和报告里单独列出。
#
# 每行一条：<种类> <路径模式>        行内 # 之后为注释
#   include  部署匹配的文件
#   exclude  即使被 include 匹配也不部署（已确认游戏不读取）
#   doubt    存疑：不部署，单独列出
# 判定顺序：doubt > exclude > include；三者都不匹配的文件不部署。
# 路径相对源目录，用 /；* 不跨目录，** 跨任意层目录，? 匹配一个字符；不分大小写。
# 只写已逐个确认过的扩展名。新增一种文件类型时，先确认游戏会读取，再加一行 include。
