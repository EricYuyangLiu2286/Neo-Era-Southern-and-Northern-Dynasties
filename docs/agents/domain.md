# Domain Docs

本项目采用 single-context（单一领域文档）布局。

## 探索前读取

- 根目录 `GLOSSARY.md`：项目术语。
- `docs/adr/`：与当前工作有关的设计决策。

文件尚不存在时直接继续，无须提示缺失或预先创建空文件。
`domain-modeling` 在术语或决策实际确定时创建相应文档。

## 术语与决策

任务标题、设计提案、诊断假设和测试名称沿用术语表中的定义。
需要的概念尚未收录时，先核对项目既有用语；
确有缺口时记录给 `domain-modeling`。

方案与已有 ADR 冲突时，明确指出 ADR 编号、
冲突内容及重新讨论的理由。
